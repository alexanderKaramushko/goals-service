# Документация goals-service

Документация разделена по ответственности:

- **Бизнес** — [бизнес-правила](./business/business-rules.md): разрешения,
  ограничения, статусы и планы развития;
- **Система** — [системная спецификация](./system/system-specification.md) и
  [модель данных](./system/data-model.md): API, обработка запросов и хранение
  данных;
- **Архитектура** — [обзор архитектуры](./architecture/overview.md) и
  [архитектурные решения](./architecture/adr/testing.md): компоненты системы,
  внутренние слои Goals Service и принятые технические решения.

Инструкции по запуску, разработке, тестированию и эксплуатации находятся в
корневом [README](https://github.com/alexanderKaramushko/goals-service/blob/main/README.md).
